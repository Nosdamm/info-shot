# InfoShot

**InfoShot**, AI video/görsel üretim süreçlerinde yerel shot reçetesi ve otomasyon motorudur. Higgsfield ve diğer platform indirmelerini otomatik yakalar, sahnelerle eşleştirir ve projeleri senkronize eder.

## Özellikler
- **Yerel Dashboard & Reçete Masası:** Projeleri ve sahneleri web arayüzünden görsel olarak takip edebilme.
- **Otomasyon Motoru:** İndirilen çıktıları ilgili sahne klasörlerine otomatik yönlendirme ve organize etme.
- **Referans Yönetimi:** Sahnelere ait prompt, stil ve referans görsellerini proje bazında saklama.

## Başlangıç
Projeyi çalıştırmak için:
```bash
python3 app/studio_engine.py
```
Tarayıcınızda `http://localhost:8765` adresini açarak stüdyoya erişebilirsiniz.
